# Provisional Licensing Structure

Blocksmith is intended to remain free, inspectable, repairable, and difficult to capture behind a closed service.

The provisional stack, pending legal review before a public production release, is:

- **Software:** GNU AGPL-3.0-or-later
- **Printable hardware and source geometry:** CERN-OHL-S-2.0
- **Documentation and educational material:** CC BY-SA 4.0

The initial v0.1 repository uses AGPL-3.0-or-later as its default license while the license boundaries and authoritative physical-design sources are assembled.

Contributors certify origin using Developer Certificate of Origin sign-off. Donated profiles must include measurement provenance and must not contain unauthorized third-party logos or copied proprietary geometry.

Commercial hats may be referenced descriptively for compatibility or research, but public presets should use original descriptive names, original measurements, and clear provenance.
