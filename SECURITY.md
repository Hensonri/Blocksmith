# Security Policy

Blocksmith v0.1 is local-first and does not include accounts, telemetry, a remote database, or automatic uploads. Customer and project information remains in browser storage unless the user explicitly exports a file.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting or draft security-advisory feature for the repository. Do not publish exploit details in a public issue before a fix is available.

Useful reports include the affected revision, platform/browser, reproduction steps, impact, and any proposed mitigation. Do not include real customer records, private hat profiles, credentials, or unrelated personal information.

## Supported versions

Until the first public release, only the latest repository revision is supported. Pre-alpha geometry must also pass physical manufacturing validation; a closed mesh is not a safety certification.
