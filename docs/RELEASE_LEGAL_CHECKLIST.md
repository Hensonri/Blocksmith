# Pre-Release Rights and Provenance Checklist

No public release is approved until every required item is checked for the exact candidate commit and archive.

## Name and identity

- [ ] U.S.-licensed trademark attorney clears **Blocksmith for Hat Makers** for the proposed software, downloadable files, education, community, and support uses.
- [ ] Relevant federal records and common-law results are rechecked and archived.
- [ ] All public surfaces use the full name; no `®` symbol is used without registration.
- [ ] Backup names and a string-replacement plan are retained until clearance.

## Copyright and assets

- [ ] Every shipped image appears in `docs/ASSET_PROVENANCE.md` with a cleared status and SHA-256 hash.
- [ ] No competitor screenshot, catalog image, logo, trade dress, or restricted reference is included.
- [ ] Every generated or photographed replacement has its creation record archived.
- [ ] Every released STL is reproducible from first-party governed source or separately identified approved material.
- [ ] No user-supplied or downloaded STL/3MF reference file is present anywhere in the release.

## Licenses and dependencies

- [ ] Root `LICENSE` contains the complete AGPL-3.0 text.
- [ ] Complete CERN-OHL-S-2.0 and CC BY-SA 4.0 texts are included under `LICENSES/`.
- [ ] `docs/LICENSING.md` accurately maps every path to a license.
- [ ] `THIRD_PARTY_NOTICES.md` is regenerated from the final lockfile.
- [ ] Installer bundles preserve every dependency notice and required license text.
- [ ] Release source and Corresponding Source are offered as required by AGPL-3.0-or-later.

## Contributions and history

- [ ] Every outside contribution has DCO sign-off and provenance.
- [ ] Founder-authored commits are documented where historical commits lack sign-off.
- [ ] Release commit, tag, changelog, checksums, and evidence archive are immutable and backed up.

## Validation honesty

- [ ] Full-size pin validation is complete for the intended printer/material combinations.
- [ ] One-quarter-scale crown/profile measurements are recorded.
- [ ] No provisional profile is advertised as physically validated.
- [ ] Export gates and safety language match the release's actual evidence.

## Final approval

- [ ] Candidate ZIP/installer contents were enumerated and compared with the source manifest.
- [ ] Malware/dependency/security checks passed.
- [ ] Rich Henson approved the exact candidate after reviewing the validation and legal hold items.
