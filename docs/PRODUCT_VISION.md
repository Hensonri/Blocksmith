# Product Vision

Blocksmith should feel like entering an old milliner's workshop where every tool has a purpose and none requires a mechanical-engineering degree to use.

## The primary object: a Hat Project

A Hat Project binds together:

- customer or wearer measurements and optional conformateur/formillion trace;
- standard or personalized head profile;
- crown, brim, tooling, stand, and accessory parameters;
- felt or other hat material;
- printer, filament, calibration, and assembly information;
- revisions, inspection results, and photographs;
- export artifacts, authorship, lineage, and checksums.

The governing workflow is:

**Capture → Design → Prepare → Print → Use → Verify → Preserve/Share**

## First-use promise

A new user who has no trace file and no CAD experience must be able to choose a size, choose a standard profile, create a standard open-crown block, understand what is provisional, produce a small proof, and know what to do when the print is unsatisfactory.

## Interface character

The supplied Blocksmith Studio illustration is the visual source of truth: dark wood, brass, parchment, tools, shelves, and the feeling of a working historical shop. The character must not reduce contrast, keyboard access, or discoverability. Controls retain location and meaning as the product grows.

## Finished-hat view

Finished-hat visualization is required. It translates tooling choices into the object the maker actually cares about while maintaining a strict distinction between **illustrative intent** and **manufacturing geometry**.

## Portability and resilience

Core design and export must work offline on Windows, macOS, and Linux, with Chromebook support where practical. Data uses documented, migratable formats. Releases should eventually be signed, mirrored, archived, and reproducible.
