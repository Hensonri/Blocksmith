# First-Hat New-User Test

## Test goal

Determine whether a likely Blocksmith user can create and preserve a standard open-crown Hat Project without private coaching, while correctly understanding the difference between intent visualization and physically validated manufacturing geometry.

## Participants

Run small iterative rounds with different mental models:

1. a hatter with little CAD or 3D-printing experience;
2. an experienced 3D printer who is new to hatmaking;
3. a working hatter who can challenge terminology and shop workflow;
4. an accessibility participant who primarily uses keyboard navigation or magnification;
5. one true beginner to both domains for the final clarity check.

## Scenario A — the first standard block

> You want to restore or make a size 7 1/4 felt hat. Create a Regular Oval standard open-crown block with a 6-inch crown and a 2.5-inch finished brim intent. Prepare a proof print and preserve enough information to repeat the work later.

Observe whether the participant can:

- identify Capture as the starting point;
- understand that no trace is required;
- choose finished size 7 1/4 and R / Regular Oval;
- recognize Open Crown as tooling and a crease as finished-hat intent;
- switch between Block and Finished Hat views;
- reach the calibration gate without surprise;
- export a quarter-scale proof STL;
- explain why full-scale export is locked or unlocked;
- add printer and filament information;
- record satisfaction or use the troubleshooting return path;
- export the editable project record and shop traveler.

## Scenario B — alternate profile pressure test

> Create a Long Oval project and attempt to prepare a full-size print.

The participant should encounter a plain-language provisional-profile explanation and should not conclude that the shape has been physically validated.

## Mistake and recovery checks

- Switch from metric to SAE and back.
- Enter circumference instead of hat size.
- Select XLO and look for validation status.
- Change crown height and taper; confirm the central hat changes visibly.
- Mark a print unsatisfactory; confirm calibration, printer, and filament records are offered as diagnostic evidence.
- Reload the application and confirm the current project survives.
- Import an exported project and confirm it remains editable.

## Launch gates

- No participant produces a wrong-size full-scale file because of ambiguous units, profile state, or hat-size language.
- A standard open-crown proof can be exported without outside coaching.
- Full-scale export cannot bypass the defined readiness gate.
- The user can recover from an unsatisfactory print without knowing our internal design history.
- Every interactive control is reachable and understandable with a keyboard.
- No P0/P1 browser or responsive-layout defects remain.

Every hesitation, workaround, explanation request, and misread term is a finding—even when the participant eventually succeeds.
