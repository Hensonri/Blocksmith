# Roadmap

## v0.1 — First-Hat Foundation

- Standard open-crown R/RO/LO/XLO catalog with validation states
- Size/circumference input and dual units
- Interactive tooling and finished-hat intent preview
- Closed STL proof generator
- Calibration, printer, filament, verification, and project records
- Local autosave and open JSON export
- Shop traveler and first-user test plan

## v0.2 — Physical Geometry Recovery and Validation

- Import authoritative BMFS v0.1/v0.2/v0.3, Prototype 003, and coupon sources
- Render and checksum known SCAD/STL artifacts
- Compare generated crown openings with measured reference blocks and hats
- Validate RO and LO profile families
- Add printer-envelope, wall-thickness, collision, and seam analysis
- Package `.blocksmith` as an open ZIP with manifest and migrations
- Add 3MF as primary manufacturing export with STL fallback

## v0.3 — Complete Tooling Ecosystem

- Four-piece BMFS brim flanges and size bridges
- Universal stand and interchangeable tops
- Personalized conformateur/formillion traces
- Crown plates, sandwich tooling, stretchers, and shape keepers
- Click/drag brim editing, locked points and lines, symmetric/asymmetric quadrants
- Finished-hat visualization tied to crown and brim tooling

## v1.0 — Public Release

- Small-round usability results incorporated
- Signed Windows, macOS, and Linux installers
- Offline update checks with explicit consent
- Accessibility and security review
- Verified release artifacts, mirrors, archives, migration tests, and recovery documentation
- Public contribution, profile-provenance, trademark, and release-governance policies
